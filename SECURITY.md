# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately via
[GitHub Security Advisories](https://github.com/SanaVarsi/specdbt/security/advisories/new).
You should get a response within a few days.

## Supported Versions

specdbt is pre-1.0; only the latest published release on PyPI is supported.
